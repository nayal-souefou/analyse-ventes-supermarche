# Schéma du dataset Supermarché

## Source
Kaggle — Supermarket Sales Dataset
1000 transactions

## Description des colonnes

| Colonne | Type | Description |
|---|---|---|
| product_line | text | Catégorie de produit |
| unit_cost | float | Prix unitaire du produit |
| quantity | int | Quantité achetée |
| 5pct_markup | float | Marge de 5% |
| revenue | float | Chiffre d'affaires de la transaction |
| date | text | Date de la transaction |
| time | text | Heure de la transaction |
| payment_method | text | Moyen de paiement (Cash, Ewallet, Credit card) |
| cogs | float | Coût des marchandises vendues |
| gm_pct | float | Pourcentage de marge brute |
| gender_customer | text | Genre du client |
| city | text | Ville du supermarché |
| rating | float | Note de satisfaction du client |

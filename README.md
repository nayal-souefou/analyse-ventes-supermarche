# Analyse des ventes d'un supermarché - Python

Analyse exploratoire des ventes d'un supermarché avec Python et Pandas, répondant à des questions métier concrètes (chiffre d'affaires, comportement client, catégories de produits, moyens de paiement).

## Dataset
Source : Kaggle — Supermarket Sales Dataset
1000 transactions, colonnes : product_line, unit_cost, quantity, revenue, date, time, payment_method, cogs, gm_pct, gender_customer, city, rating.

## Outils
- Python (Pandas, Matplotlib)
- Jupyter Notebook
- Git & GitHub

## Structure du projet
- `analyse_supermarche.ipynb` — notebook principal avec l'analyse
- `questions_metier.md` — questions métier et interprétations
- `README.md` — ce fichier

## Questions métier traitées
1. Statistiques de base (CA total, moyenne, max, min)
2. Chiffre d'affaires par catégorie de produit
3. Ventes totales par moyen de paiement
4. Note moyenne des clients par ville
5. Répartition des ventes par genre
6. Quantité vendue par catégorie de produit
7. CA moyen par moyen de paiement
8. Top 3 des catégories les plus rentables

## Principaux résultats
Les ventes sont réparties de façon équilibrée entre les catégories de produits. Les moyens de paiement les plus utilisés varient selon les villes. Les femmes et les hommes contribuent de façon quasi équivalente au chiffre d'affaires global.
